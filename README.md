# MiniBurn

MiniBurn é uma engine gráfica experimental criada em C utilizando SDL2 e OpenGL.

Ela serve como um projeto de aprendizado e como teste para a futura Burnout Engine.

## Tecnologias

- C
- OpenGL
- SDL2
- GLAD
- stb_image

## Funcionalidades atuais

- [x] Janela e contexto OpenGL
- [x] Renderização 3D
- [x] Shaders
- [x] Texturas
- [x] Depth testing
- [x] Matrizes e vetores matemáticos próprios
- [x] Câmera
- [x] Input pelo teclado
- [ ] Sistema de física
- [ ] Editor
- [ ] Mais sistemas da Burnout Engine
